# Nucleotide diversity and LD decay

Nucleotide diversity and linkage disequilibrium decay analyses were independently performed on datasets generated using the `DP9_Hap2` and `Tuono_Hap1` reference assemblies. The same analytical settings were applied to both datasets; commands are therefore reported once in a reference-independent format.

## Nucleotide diversity

Nucleotide diversity (π) was estimated separately for the `K1_Pw` and `K2_Pd` groups using the `set2` datasets and VCFtools v0.1.14.

Population-specific subsets were defined using sample-ID lists provided in the `metadata` directory.

Nucleotide diversity was calculated in non-overlapping 50-kb windows using `--window-pi 50000`.

The corresponding command is provided in `01_nucleotide_diversity.sh`.

## LD decay



Genome-wide LD decay was estimated separately for the K1_Pw and K2_Pd groups starting from the set1 datasets. Population-specific PLINK datasets were generated by retaining the corresponding sample IDs and applying a MAF threshold of 0.01.

Pairwise LD (r²) was calculated for all SNP pairs within a maximum physical distance of 500 kb using PLINK v1.9 with --ld-window 99999, --ld-window-kb 500, and --ld-window-r2 0.

Genome-wide LD decay was modelled by fitting the Hill and Weir expectation for r² as a function of physical distance using R v4.5.1 and a script adapted from the implementation of Marroni et al (2011). Following the same implementation, the LD half-decay distance was estimated as the physical distance at which the fitted r² reached half of its maximum estimated value.

Population-specific PLINK dataset preparation and pairwise LD calculation are reported in `02_LD_dataset_and_calculation.sh`, whereas genome-wide fitting, half-decay estimation, and plotting are reported in `03_LD_decay_HillWeir.R`.
