# Allele-specific expression analysis at the S locus

RNA-seq reads from pistil and stamen tissues were processed and independently aligned against the corresponding haplotype-resolved `Tuono` and `DP9` genome assemblies.

The computational workflow included read quality filtering, genome alignment, library-strandness assessment, transcript reconstruction at the S locus, identification of the S-RNase allele, and allele-specific read quantification.

## Read quality control

Raw RNA-seq reads were quality-checked and filtered using fastp v1.0.1.

Sequencing adapters were removed, and reads with a Phred quality score <20 or a post-trimming length <35 bp were discarded.

Commands are reported in `01_fastp_QC.sh`.

## RNA-seq alignment

Each haplotype assembly was indexed with STAR v2.7.11b using its GTF annotation and `--genomeSAindexNbases 13`. Trimmed reads were then aligned independently against the corresponding haplotype-resolved genome. Alignments used 10 threads, `--twopassMode Basic`, and `--outSAMstrandField intronMotif`, and were written as coordinate-sorted BAM files.

Commands are reported in `02_STAR_mapping.sh`.

## Library strandness

RNA-seq library strand-specificity was assessed using `infer_experiment.py` from RSeQC v5.0.4, sampling 1,000,000 reads from each coordinate-sorted BAM against a BED12 gene model of the same haplotype.

The corresponding command is reported in `03_RSeQC_strandness.sh`.

## S-locus transcript annotation

S-locus transcript models were reconstructed using StringTie v2.2.3 from RNA-seq alignments restricted to the chromosome 6 region bounded by the best BLASTn matches to the S-haplotype F-box (SFB) and S locus F-box (SLF) genes (GenBank accessions MH316096.1 and MH316056.1, respectively), previously reported to flank the S locus.

Two complementary transcript-assembly strategies were used on the S-locus alignments:

- reference-guided assembly using the haplotype annotation (`-G`) and a minimum splice-junction support of 3 (`-j 3`);
- de novo transcript assembly without reference annotation, also with `-j 3`.

Transcript models generated by the two approaches were subsequently combined with `stringtie --merge`, using the haplotype annotation as `-G`.

The S-RNase allele identified on `Tuono_Hap2` was assigned by nucleotide-sequence similarity against the previously characterized `Sf` S-RNase allele (GenBank accession `MH730647.1`) using the NCBI BLASTn web interface.

Commands related to transcript reconstruction are reported in `04_StringTie_S_locus_annotation.sh`.

## Allele-specific expression quantification

Allele-specific read counts for S-RNase and SFB genes were obtained using featureCounts v1.6.0 on the merged StringTie annotation. Counting was reverse-stranded (`-s 2`), paired-end (`-p`), and restricted to reads with mapping quality of at least 30.

The corresponding command is reported in `05_featureCounts.sh`.

Read counts were subsequently converted to TPM values as described in the Materials and Methods.
