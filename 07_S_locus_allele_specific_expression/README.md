# Allele-specific expression analysis at the S locus

RNA-seq reads from pistil and stamen tissues were processed and independently aligned against the corresponding haplotype-resolved `Tuono` and `DP9` genome assemblies.

The computational workflow included read quality filtering, genome alignment, library-strandness assessment, transcript reconstruction at the S locus, identification of the S-RNase allele, and allele-specific read quantification.

## Read quality control

Raw RNA-seq reads were quality-checked and filtered using fastp v1.0.1.

Sequencing adapters were removed, and reads with a Phred quality score <20 or a post-trimming length <35 bp were discarded.

Commands are reported in `01_fastp_QC.sh`.

## RNA-seq alignment

Genome indexing and RNA-seq alignment were performed using STAR v2.7.11b.

The following parameters were explicitly used:

- `--twopassMode Basic`
- `--outSAMstrandField intronMotif`

Reads were independently aligned against the corresponding haplotype-resolved genome assemblies.

Commands are reported in `02_STAR_mapping.sh`.

## Library strandness

RNA-seq library strand-specificity was assessed using `infer_experiment.py` from RSeQC v3.1.0.

The corresponding command is reported in `03_RSeQC_strandness.sh`.

## S-locus transcript annotation

S-RNase transcript models were reconstructed using StringTie v2.2.3 from RNA-seq alignments restricted to the S-locus region of each haplotype.

Two complementary transcript-assembly strategies were used:

- reference-guided assembly using BRAKER3 gene models (`-G`) and a minimum splice-junction support of 3 (`-j 3`);
- de novo transcript assembly without reference annotation.

Transcript models generated by the two approaches were subsequently combined using `stringtie --merge` to obtain a non-redundant annotation for each haplotype.

The S-RNase allele identified on `Tuono_Hap2` was assigned by nucleotide-sequence similarity against the previously characterized `Sf` S-RNase allele (GenBank accession `MH730647.1`) using the NCBI BLASTn web interface.

Commands related to transcript reconstruction are reported in `04_StringTie_S_locus_annotation.sh`.

## S-RNase allele identification

The S-RNase allele located on `Tuono_Hap2` was identified by BLASTn comparison with the previously characterized `Sf` S-RNase allele (GenBank accession `MH730647.1`).

The corresponding command is reported in `05_BLASTn_SRNase.sh`.

## Allele-specific expression quantification

Allele-specific read counts for S-RNase and SFB genes were obtained using featureCounts v1.6.0.

The corresponding command is reported in `06_featureCounts.sh`.

Read counts were subsequently converted to TPM values as described in the Materials and Methods.
